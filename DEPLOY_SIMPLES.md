# 🚀 Deploy em 1 Clique no Netlify

## Instruções Simples

### 1. Faça Deploy no Netlify

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start)

1. Clique no botão acima
2. Conecte seu repositório GitHub
3. **NÃO PRECISA CONFIGURAR NADA!**
4. Clique em "Deploy site"

### 2. Aguarde o Build (3-5 minutos)

O Netlify vai:
- ✅ Instalar dependências
- ✅ Criar banco de dados SQLite
- ✅ Rodar migrações
- ✅ Popular dados iniciais
- ✅ Fazer build do frontend
- ✅ Deploy automático!

### 3. Acesse seu Site!

Após o deploy:
- Acesse a URL fornecida pelo Netlify
- Login: `admin@raiar.com`
- Senha: `Raiar@2026`

**Pronto! Seu sistema está no ar! 🎉**

---

## Configurações Opcionais

### Domínio Customizado

1. No Netlify: **Domain settings** → **Add custom domain**
2. Configure seu DNS
3. SSL automático!

### Mudar Credenciais Padrão

1. Faça login como admin
2. Vá em **Usuários**
3. Edite o admin e mude a senha

### Personalizar Branding

1. Acesse **Branding Kit**
2. Configure:
   - Logo
   - Cores
   - Tema (claro/escuro)
   - Favicon
   - Título SEO

## Troubleshooting

### Build falha?

- Verifique os logs no Netlify
- Tente fazer "Clear cache and retry deploy"

### Não consegue fazer login?

- Use as credenciais padrão:
  - Email: `admin@raiar.com`
  - Senha: `Raiar@2026`

### Erro 404 nas rotas?

- O Netlify pode demorar alguns minutos para propagar
- Aguarde 5 minutos e tente novamente
